Field Manual

A laminated reference card taped inside a rucksack. Warm paper, hairline rules, hi-vis amber on the actions, and rescue red doing exactly one job. It is flat and type-driven: no icons, no shadows, no imagery, because everything here is words that had to be exact.

This is not a proposal to start over. It is the palette and structure already built in the app, pushed harder — sharper hierarchy on Act, a proper treatment for cited clinical content, and a calmer defibrillator list. It is the low-risk option, and it is the one that already has a merged implementation behind it.

The bet
Calm beats loud. Under stress, a quiet screen you can read is worth more than an alarming one.
Structure
One root screen, three doors. Everything else is a pushed screen with a back button. No tabs.
Colour discipline
Amber for action, red once. Nothing else is coloured, ever.

Depth is not a mode. CPR and the defibrillator locator sit in the same place on Act for everyone; turning the Responder depth on adds a fourth button and a Settings destination, and changes nothing about the emergency path. The nav model is a single stack — a back button is the whole of the way home.

What it gains, what it costs

Gains

  • Continuity. The app already looks like this; nothing merged is thrown away.
  • It refuses the domain reflex. Not white-and-teal. It reads like field equipment, which is what it is.
  • Red stays meaningful. One red thing on the whole app, so red itself is the signal.
  • Type carries everything, so there is nothing to misread at arm’s length and nothing to break at 200% zoom.

Costs

  • It is quiet. A frightened stranger may not immediately see the two secondary destinations, because nothing about them shouts.
  • No iconography means the AED path relies on reading, in the exact moment reading is hardest.
  • The list is the only AED view. Finding a defibrillator on a map is two taps and a screen away, which is one too many when someone is walking.

How to read this file. Frames are 320 × 700, drawn at roughly real size for a phone held one-handed. Every frame is live HTML — resize the window, or hit ⌘+ to zoom, and it reflows. The light theme follows your system setting; the second Act frame is forced dark so both can be seen at once. Clinical strings are the real cited record or an honest content slot — never invented.
