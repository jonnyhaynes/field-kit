Field Kit · redesign · direction

The violet register

A deliberate reversal of the palette and the shape language: a violet brand on tinted neutrals, 20–30px radii, a floating bottom bar with a round red emergency button, a gradient hero carrying the wordmark, and soft pastel accents. Dark is the default and the priority; light is designed alongside it, not after.

What does not change: red is still the emergency action and nothing else, unverified data is still labelled, offline is still the default path, and the app still never diagnoses. The reference's learning features — courses, quizzes, certificates, streaks, dashboards — are a different product and are not here; ask for them separately.

Neutrals are tinted violet, not grey
The canvas is a violet near-black, not a cool blue-black — that tint is what makes the surfaces read as one family with the brand, and it is the single change that does most of the work.
Red is still the emergency, and only that
The reference puts a round red button in its bar too, so this survives the re-register. Every other red has to go: the AED flag action is a pink chip now, not a red label.

Does the type have to change?

Yes, and it is doing more work than the palette does. The reference's warmth comes largely from a round geometric sans; Overpass is a wide, blunt signage face, so inside violet rounded cards it reads as an instrument that wandered into a friendly app. The recommendation is the middle column — Nunito Sans: round, but still very legible at 13px, which matters because this is read standing up. IBM Plex Mono stays for measured values: words in one face, numbers in the other, which is the idea that keeps it reading as equipment.

What this costs, and what it does not touch

The cost: every surface token changes
Palette, radii, elevation, the bottom bar and the text face are all touched, so it is a re-register rather than a reskin: theme.ts, the surface compositions, every component, and the screens that gain a hero or a 2-up grid. IBM Plex Mono survives; Overpass does not.
The line it does not cross
Clinical content, offline rules, consent, and the data model are untouched. The app still reproduces guidance rather than writing it, still never diagnoses, and still keeps records on the device. A design change here is not a licence to loosen any of that.

Before this becomes code

This is a bigger change than the surface pass, and it reverses a register the repo documents as deliberate. So it wants its own issue and plan — the agreed look, the palette in both schemes, the component list, and what happens to the shipped beacon decision in plan 35 §2/§9 — before anything is written.

What I need from you: whether this register is right, and whether "feel" stops at the visual language (as drawn here) or extends to the reference's learning features — courses, quizzes, certificates, progress dashboards. The second is a scope change, not a style one.

How to read this. Set in the real bundled Overpass and IBM Plex Mono; screen copy is the app's own. Dark frames are the default register; the light frames are the same components retuned. What this is not: a finished layout, and not yet implemented. Spacing is not re-tuned per screen, the palette is a proposal rather than a measured conversion, and contrast on the light theme in particular needs measuring before it ships.
