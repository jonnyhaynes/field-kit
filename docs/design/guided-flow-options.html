Guided flow — two navigation options

Same content, same four destinations. The question is what is a step and what is a place you can jump to. Clinical strings are deliberately left as content slots — they get filled from the sourced, cited records, not written here.

Palette is a first pass to react to: warm graphite and hi-vis amber, with red used for exactly one thing. Not teal, not clinical white.

Option A — Linear, 4 screens

AED is step 4. You answer a question, then call, then do compressions, then find a defibrillator. One path, no choices.

Cost: a passer-by who has just been asked to fetch a defibrillator must answer two questions and open a call screen before they can see where one is. It also models one person doing everything in order, which is not how an arrest is usually worked.

Gain: the second rescuer leaves immediately with the locator open, while the first keeps doing compressions. Nothing is buried, and it comes in under the four-screen ceiling with a screen to spare.

What I'd ship

Option B, for three reasons.

  • Fetching the AED is a parallel job, not a step. It's normally a different person to whoever is doing compressions, so it shouldn't sit behind a sequence that person already passed.
  • It survives the stranger case. Someone told "go and find a defibrillator" can act on the first screen, without answering questions about a casualty they haven't seen.
  • Call 999 is still the default. B changes what's reachable, not what's obvious — the red action stays the single dominant target on the first screen.

The honest counter-argument for A is that choice costs something under stress, and a linear flow can't be got wrong. If you'd rather eliminate the choice, A is the safer shape — it just pays for that with the AED being four taps away.
