FieldKit — the whole app

The first mock-up showed only the Guided emergency path, because that was all the 3-vs-4-screens question needed. This is everything you originally asked for, and where each piece sits.

One structural decision drives it: depth is not a mode. Call 999, CPR and the defibrillator locator are always present, in the same place, for everyone. The Responder depth adds tools on top rather than swapping the app out — so a trained responder never loses the fast path, and an untrained user never meets a mnemonic form.
